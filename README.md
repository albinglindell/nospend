# No Spend

A simple mobile-first calendar to track daily spending. Tap a day, log how much you spent, and see your month at a glance.

## Color coding

- **Green** — spent 0 (no-spend day)
- **Yellow** — spent up to 200
- **Red** — spent over 200

## Tech

- React 18 + TypeScript + Vite
- Ant Design (modal & input)
- dayjs (date handling)
- `localStorage` for persistence

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
